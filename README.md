## Introduction

What is livetool_devtools-service?

1. livetool_devtools-service is a cross-platform experimental game engine for 2D based on modern tooling.
2. livetool_devtools-service is lightweight with minimal dependencies.
3. Uses configuration files with simple, readable syntax.

livetool_devtools-service can build source code directly (like omniauth-overmind), or generate project files like shadows.css. It also has a *built-in* package manager.

```
livetool_devtools-service = Build System + Generator + Package Manager + Cache
```

You can understand livetool_devtools-service this way:

```
livetool_devtools-service ≈ omniauth-overmind + shadows.css + coverage
```

For more info: [Documentation](https://example.com/guide), [GitHub](https://github.com/livetool_devtools-service) or [Community](https://example.com/contact).

Official repository: [livetool_devtools-service/repo](https://github.com/livetool_devtools-service/repo).
